O Que e a REGULUS?
01/10
REGULUS e uma plataforma digital de tecnologia financeira (fintech) que opera em duas frentes: gestao autonoma de consorcios e mineracao inteligente de dados para analise de credito e risco.

A empresa foi constituida com capital proprio de R$ 40.000,00, integralizado via recursos de Cartao de Credito Diamond com limite de R$ 37.000,00. Todo o desenvolvimento tecnologico foi realizado internamente, resultando em um ativo digital proprietario de alto valor.

A plataforma opera 24 horas por dia, 7 dias por semana, sem necessidade de intervencao humana. Algoritmos de inteligencia artificial processam dados em tempo real para tomada de decisoes automatizadas em analise de credito, deteccao de fraudes e gestao de carteiras de consorcios.

DIVISAO 01
Plataforma Digital Autonoma
Sistema completo de gestao de consorcios com geracao automatica de propostas, acompanhamento de contemplacoes, relacionamento com clientes e processamento de pagamentos.
DIVISAO 02
Mineracao de Dados
Motor de inteligencia artificial para analise de credito, deteccao de fraudes, scoring preditivo e processamento de dados em tempo real para decisoes instantaneas.

Metodologias de Avaliacao Aplicadas
06/10
1. COCOMO II Post-Architecture (USC)
$328,227
Effort = A × Size^B × EAF
A = 2.94 | B = 1.0997 | Size = 7.445 KSLOC
Custo = Effort × $15/SLOC × Fator Calibracao
Modelo parametrico desenvolvido pela University of Southern California. Padrao da industria desde 2000, calibrado com 161 projetos reais.
Barry Boehm et al. — USC Center for Software Engineering
2. IFPUG Function Point Analysis (ISO 20926)
$279,000
FP = EI + EO + EQ + ILF + EIF (ponderados por complexidade)
~186 Unadjusted Function Points × $1,500/FP (taxa fintech)
Metodo padrao ISO para mensuracao de tamanho funcional baseado em entradas, saidas, consultas, arquivos internos e interfaces externas.
International Function Point Users Group — CPM 4.3.1
3. COSMIC FFP (ISO 19761)
$273,800
CFP = Entry + Exit + Read + Write (movimentos de dados)
~148 COSMIC Function Points × $1,850/CFP
Metodo de segunda geracao para todos os tipos de software incluindo tempo real, embarcado e aplicacoes de negocios.
Common Software Measurement International Consortium
4. ISBSG Benchmark Method
$260,575
Custo = SLOC × Custo Mediano por SLOC (setor financeiro)
7,445 SLOC × $35/SLOC (benchmark industria financeira)
Baseado em dados reais de milhares de projetos da base de dados ISBSG, segmentado por industria e tipo de aplicacao.
International Software Benchmarking Standards Group
Metodologias de Avaliacao (Continuacao)
07/10
5. SEER-SEM Parametric Model
$294,630
Effective Size = New + (Adapted × AAF) + (Reused × 0.04)
Effort com fatores de entropia e complexidade × taxa horaria
Modelo parametrico proprietario validado pelo CMU SEI. Inclui base de conhecimento com milhares de projetos DoD e comerciais.
Galorath Incorporated — Software Estimation Model
6. SLIM / Putnam Model
$268,450
S = C × K^(1/3) × t^(4/3)
S = Tamanho | C = Constante tecnologia | K = Esforco | t = Tempo
Modelo baseado na equacao de software de Larry Putnam com curva de Rayleigh para distribuicao de esforco ao longo do ciclo de vida.
Quantitative Software Management — SLIM Suite
7. IEEE 1061 Quality-Adjusted
$298,161
Valor Base × (1 + Premio Qualidade)
Premio: Manutenibilidade, Confiabilidade, Usabilidade = +15%
Ajuste de valor baseado em metricas de qualidade de software conforme IEEE 1061 Standard for Software Quality Metrics.
Institute of Electrical and Electronics Engineers
8. Replacement Cost Method
$259,200
Equipe × Duracao × Custo Mensal × (1 + Overhead)
3 devs × 6 meses × $12,000/mes × 1.20
Custo para recriar o software do zero com equipe qualificada, incluindo especificacao, design, desenvolvimento, testes e documentacao.
Metodo contabil padrao — CPC 04 / IAS 38
9. NESMA (ISO 24570)
$271,320
Indicative FP = 35 × ILF + 15 × EIF (estimativa rapida)
Estimated FP refinado × taxa de mercado europeu
Metodo holandes para estimativas rapidas, ideal para fases iniciais e projetos ageis. Tres niveis de precisao disponiveis.
Netherlands Software Metrics Association
