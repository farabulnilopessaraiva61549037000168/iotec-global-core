2. Metodologia de Avaliacao

2.1 COCOMO II — Constructive Cost Model

Modelo parametrico desenvolvido pela University of Southern California para estimativa de custo de desenvolvimento de software. Utiliza SLOC (Source Lines of Code) como metrica base.

Effort (PM) = A × Size^B × EM
A = 2.94 (calibracao padrao)
B = 1.0997 (projeto organico)
Size = KSLOC = 7.445

2.2 Custo de Desenvolvimento por Linha

Baseado em benchmarks internacionais para desenvolvimento fintech:

Custo Base: USD 15.00/SLOC (mercado medio EUA)
Fator Fintech: 2.0x (complexidade regulatoria)
Fator Brasil: 0.65x (ajuste paridade)
Custo Ajustado: USD 15 × 2.0 × 0.65 = USD 19.50/SLOC

2.3 Replacement Cost Method

Custo estimado para recriar o software do zero com equipe qualificada, considerando especificacoes funcionais, design, desenvolvimento, testes e documentacao.
